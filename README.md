# 🤝 Crowd Funding WebApp

A full-stack **Crowdfunding Platform** built with **React, Node.js, and Firebase**.
Users can create campaigns, support causes, and track donation progress in real-time. 💸

### 🚀 Live Demo

🔗 Live Demo: https://cute-heliotrope-b7fa4b.netlify.app

---

### 🛠️ Tech Stack

* ⚛️ **Frontend:** React.js, HTML, CSS
* 🔙 **Backend:** Node.js
* 🔥 **Database & Auth:** Firebase
* 🎨 **Styling:** Responsive CSS / Tailwind
* ⚡ **Build Tool:** Vite

---

### ✨ Features

* **Create Campaigns:** Users can start their own fundraising campaigns with details and images.
* **Secure Authentication:** Login and Signup functionality powered by Firebase.
* **Donation System:** Real-time updates on funds raised.
* **Responsive Design:** Works seamlessly on mobile and desktop.
* **CRUD Operations:** Users can update or delete their own campaigns.

---

### 📦 Installation

To run this project locally, follow these steps:

1. **Clone the repository:**
  
   git clone [https://github.com/prncenium/crowdFunding-website.git](https://github.com/prncenium/crowdFunding-website.git)

2.Navigate to the project directory:
   cd crowdFunding-website
   # If the code is inside the 'evaluation' folder, use: cd evaluation
   
3.Install Dependencies:
  npm install

4.Run the App:
  npm run dev
